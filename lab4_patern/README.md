# Лабораторная работа №4: Применение паттернов проектирования в системе учета сотрудников

## Описание

Лабораторная работа представляет собой комплексный рефакторинг системы учета сотрудников с применением **6+ паттернов проектирования**. Проект демонстрирует практическое применение порождающих, структурных и поведенческих паттернов для улучшения архитектуры и расширяемости системы.

## Цель работы

Освоить практическое применение паттернов проектирования для рефакторинга и улучшения кодовой базы системы учета сотрудников. Получить навыки применения различных паттернов для решения типичных задач проектирования ПО.

## Реализованные паттерны

### Порождающие паттерны (Creational)

1. **Singleton** - `DatabaseConnection` для управления единственным подключением к БД SQLite
2. **Factory Method** - Рефакторинг `EmployeeFactory` с абстрактными и конкретными фабриками
3. **Builder** - `EmployeeBuilder` с fluent-интерфейсом для пошагового создания сложных объектов

### Структурные паттерны (Structural)

4. **Decorator** - `BonusDecorator`, `TrainingDecorator` для динамического добавления функциональности сотрудникам

### Поведенческие паттерны (Behavioral)

5. **Strategy** - `BonusStrategy`, `PerformanceBonusStrategy`, `SeniorityBonusStrategy` для гибкого расчета бонусов
6. **Observer** - `NotificationSystem`, `LoggingSystem` для системы уведомлений об изменениях

### Система обработки ошибок

7. **Кастомные исключения** - Полноценная система исключений
